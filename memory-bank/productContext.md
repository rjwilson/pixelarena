# Product Context: Pixel Combat Arena (Prototype)

**Why this project exists**: To explore and demonstrate core tactical combat mechanics in a web-based format, inspired by tabletop RPGs like D&D.

**How it should work**:
- Turn-based combat on a 2D grid.
- Characters act based on initiative.
- Simplified action economy (Move and Standard Action).
- Combat resolution using d20 rolls vs. AC, with critical hits/misses.
- Damage calculation based on dice rolls and character stats.
- Basic AI for enemy characters.
- Mouse-driven controls for player actions.

**User experience goals**:
- Engaging tactical decision-making.
- Clear visual feedback for actions and outcomes.
- Functional UI providing necessary information and controls.
- Pixel art aesthetic guiding visuals.
