# Project Brief: Pixel Combat Arena (Prototype)

**Project Goal**: To create a playable prototype demonstrating core tactical combat mechanics, including grid-based movement, an action economy, d20-based combat resolution, and basic enemy AI, all presented with a clear pixel art visual style. A significant emphasis is placed on robust code and automated testing.

**Core Concept**: A 2D turn-based tactical combat web application where a small party of player-controlled characters battles AI-controlled enemies on a grid. The game aims to capture the tactical decision-making of tabletop RPG combat in a streamlined digital format, running locally in a web browser.
